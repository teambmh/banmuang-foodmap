# บ้านม่วง FoodMap

เว็บค้นหาร้านอาหารในอำเภอบ้านม่วง จังหวัดสกลนคร

## วิธีใช้กับ GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดเข้า repository
2. ไปที่ Settings > Pages
3. Source เลือก Deploy from a branch
4. Branch เลือก main และ /root
5. กด Save
6. รอสักครู่ แล้วเปิดลิงก์ GitHub Pages

## หมายเหตุ

ใช้ OpenStreetMap + Overpass API ฟรี 100%
ข้อมูลร้านอาจไม่ครบเหมือน Google Maps และอาจต้องเพิ่มข้อมูลร้านใน OpenStreetMap เพิ่มเติม
